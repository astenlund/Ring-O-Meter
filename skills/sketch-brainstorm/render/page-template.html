Vocabulary
  • Arrow A to B = Move
  • + / ++ near element = Larger
  • − / −− near element = Smaller
  • Strikethrough = Remove
  • Drawn element in place = Add
  • Grey line = Align (position = axis; c/t/b/l/r)
  • Squiggle inside = Lorem ipsum
  • Text in element = UI copy for that element
  • Text in margin = Instruction for Claude
  • Text + arrow = Instruction about that element

Color on lines disambiguates: red = Remove, grey = Align. Green emphasises Add when natural.
